# Публикация юридических страниц Make a Wish

Эта папка готова для загрузки в корень репозитория:

https://github.com/makeawish-privacy/makeawish-privacy

## Что загрузить

Загрузите в корень ветки `main` все файлы из этой папки. Старые `PRIVACY_POLICY.md` и `DELETE_ACCOUNT.md` замените новыми версиями.

## Как включить GitHub Pages

1. Откройте репозиторий → **Settings**.
2. Слева выберите **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Branch: **main**; Folder: **/(root)**.
5. Нажмите **Save** и дождитесь публикации.

Ожидаемые публичные адреса:

- Главная: https://makeawish-privacy.github.io/makeawish-privacy/
- Privacy Policy: https://makeawish-privacy.github.io/makeawish-privacy/privacy-policy.html
- Terms of Use: https://makeawish-privacy.github.io/makeawish-privacy/terms-of-use.html
- Account Deletion: https://makeawish-privacy.github.io/makeawish-privacy/account-deletion.html

Проверьте каждый адрес в приватном окне браузера: страницы должны открываться без входа в GitHub.
